
# AI 기반 적응형 사회 추리 게임 개발

> AI 주민들이 서로 기억하고 영향을 주고받는 사회에서 사건을 해결하는 추리 게임

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | AI 기반 적응형 사회 추리 게임 개발 |
| 게임명 | 미정 |
| 개발 형태 | 2D 픽셀 아트 기반 웹 게임 |

## 1. 프로젝트 개요

플레이어가 작은 마을에서 발생한 사건을 조사하는 AI 기반 추리 게임이다.

마을 주민들은 각자의 성격, 기억, 비밀, 인간관계를 가지고 생활한다. 범인이 아니더라도 개인적인 사정으로 거짓말할 수 있으며, 플레이어의 행동이나 다른 주민과의 상호작용을 통해 생각과 행동이 달라질 수 있다.

**사건의 진실은 고정되어 있지만, 진실에 도달하는 과정은 플레이어마다 달라진다.**

### 주요 게임 기능

- **마을 탐색:** NPC들의 일상생활과 상호작용 관찰
- **현장 조사:** 장소를 탐색하고 증거 수집
- **자유 대화:** NPC에게 직접 질문하고 설득하거나 증거 제시
- **NPC 사회:** 주민들끼리 정보와 소문을 주고받으며 관계 변화
- **행동 분석:** 플레이어의 수사 방식에 따라 NPC의 대응 변화
- **추리 수첩:** 증거·진술·인물 관계를 연결해 사건 해결

## 2. 전례 없는 요소

### 핵심 차별화

**플레이어의 수사 행동이 NPC들의 인간관계를 바꾸고, 변화한 인간관계가 다시 수사 과정에 영향을 주는 양방향 구조.**

예를 들어 다음과 같은 상황이 가능하다.

1. 플레이어가 NPC A의 비밀을 지켜준다.
2. A가 플레이어를 신뢰하고 친구 B에게 긍정적인 경험을 전달한다.
3. B가 A의 이야기를 듣고 자신의 판단을 바꾼다.
4. B가 숨기던 정보를 자발적으로 제공한다.
5. 플레이어에게 새로운 수사 경로가 열린다.

NPC는 플레이어와의 대화뿐 아니라 다른 NPC와의 경험을 통해서도 행동을 바꿀 수 있다.

## 3. AI 기술 활용

| 기술 | 활용 |
| --- | --- |
| **MCP** | NPC 기억 조회, 정보 전달, 게임 내 행동 실행 |
| **Agent Skills** | NPC의 목표·기억·관계를 고려한 판단 절차 |
| **Multi-Agent** | NPC마다 독립적인 정보와 목표를 가지고 행동 |
| **Memory** | 과거 대화, 경험, 소문, 관계 변화 저장 |
| **Player Modeling** | 플레이어의 수사 행동 분석 및 NPC 대응 반영 |

일상적인 NPC 이동은 규칙 기반으로 처리하고, 주요 대화와 관계 변화에 AI를 활용한다.

## 4. 유사 게임 및 차별성

| 유사 사례 | 기존 특징 | 본 프로젝트의 차별화 방향 |
| --- | --- | --- |
| **Generative Agents (2023)** | AI 주민들의 기억·계획·사회적 상호작용 | 사회적 변화가 추리와 증거 확보에 직접 영향 |
| **Wanderfolk** | AI NPC의 기억, 소문, 관계 변화 | 주민 간 정보 전달을 수사 과정과 연결 |
| **Vaudeville** | AI 용의자와 자유로운 대화 및 심문 | NPC 간 자율적 상호작용과 행동 변화 |
| **The Guest** | 플레이어 대화 태도 분석, NPC 신뢰 변화 | 한 NPC의 변화가 다른 NPC에게 전파 |
| **Isla Verde** | 비밀을 가진 NPC 심문, 고정된 사건 진실 | NPC 간 관계 변화로 조사 경로가 달라짐 |

**독창성 판단:** 기억하는 NPC, AI 심문, 소문 전파 등은 이미 존재하는 기능이다. 따라서 개별 기능보다 **NPC 사회의 연쇄적인 변화가 사건의 조사 과정에 직접 영향을 미치는 구조**를 차별화 요소로 삼는다.

단, 해당 조합의 세계 최초 여부는 검증되지 않았다.

## 5. 개발 범위 및 고려 사항

### 예상 MVP

- 2D 픽셀 아트 기반 웹 게임
- 핵심 NPC 4명, 장소 3곳, 사건 1개
- 마을·조사·대화 화면 및 추리 수첩
- NPC 기억·신뢰·정보 공유 시스템
- 플레이어 행동에 따른 NPC 간 연쇄 반응

### 주요 기술적 도전

- AI가 사건의 사실관계를 임의로 바꾸지 않도록 제한
- NPC마다 알고 있는 정보와 전달받은 소문을 구분
- AI의 행동이 실제 게임 상태에 반영되도록 구현
- NPC의 행동 변화가 추리 불가능한 상황을 만들지 않도록 검증
- AI 호출 비용과 응답 지연 최소화

## 6. 종합 평가

| 평가 항목 | 판단 |
| --- | --- |
| **독창성** | 기존 유사 사례 존재, 핵심 메커니즘 차별화 필요 |
| **AI 기술 활용** | 높음 |
| **MCP·Agent Skills 활용** | 적합 |
| **기술적 도전** | 높음 |
| **시연 효과** | 높음 |
| **1개월 구현 가능성** | 범위를 제한하면 도전 가능 |

**결론:** AI 기술 활용과 게임성 측면에서 유망한 후보. 다만 독창성을 인정받으려면 NPC 간 연쇄적인 관계 변화가 실제 조사 경로를 바꾸는 모습을 구현하고 보여줄 필요가 있다.
